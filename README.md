# Corso Visual Basic

Raccolta di esempi ed esercizi per imparare Visual Basic, dai primi programmi
in console fino all'accesso ai database e alle interfacce grafiche.

## Esempi sulle interfacce grafiche

La cartella `9 UI` contiene due esempi Windows Forms:

1. creazione di una finestra con controlli e gestione del clic;
2. una calcolatrice con layout, eventi e validazione.

Gli esempi sono indipendenti: copiare un esempio alla volta nel file principale
di un progetto **App Windows Forms** Visual Basic. Nella stessa cartella sono
disponibili anche due esercizi in formato `.txt`.
